`EG-13_Sprint-4_PS.js` — Contains all core algorithm implementations and test cases.

## 🛠️ Implemented Functions

1. **Two Sum II (`twoSum`)** — Finds two numbers in a sorted array that add up to a target value using Two Pointers ($O(n)$ time complexity).
2. **Container With Most Water (`maxArea`)** — Computes the maximum area of water a container can store using Two Pointers ($O(n)$ time complexity).
3. **Trapping Rain Water (`trap`)** — Calculates total trapped rainwater using Two Pointers ($O(n)$ time complexity).
4. **Valid Palindrome (`isPalindrome`)** — Determines if a string is a palindrome considering only alphanumeric characters ($O(n)$ time complexity).
5. **Sliding Window Maximum (`maxSlidingWindow`)** — Tracks the maximum element in each sliding window using a Deque ($O(n)$ time complexity).
6. **Minimum Window Substring (`minWindow`)** — Finds the minimum substring containing all target characters using Sliding Window & HashMap ($O(n)$ time complexity).
7. **Binary Search (`search`)** — Locates a target element in a sorted array using Binary Search ($O(\log n)$ time complexity).
8. **Search in Rotated Sorted Array (`searchRotated`)** — Searches for an element in a rotated sorted array in logarithmic time ($O(\log n)$ time complexity).
9. **Find Minimum in Rotated Sorted Array (`findMin`)** — Identifies the minimum value in a rotated array using modified Binary Search ($O(\log n)$ time complexity).
10. **Kth Largest Element (`findKthLargest`)** — Finds the $k$-th largest element in an array using Quickselect ($O(n)$ average time complexity).
